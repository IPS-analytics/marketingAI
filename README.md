# Kotler

**Kotler** — AI-платформа для маркетологов.

Помогает работать с маркетингом в одном месте: задавать вопросы на естественном языке и получать ответы по каналам, метрикам и стратегии, без ручного сбора цифр из разных кабинетов.

---

## Что делает продукт

- **Маркетинговый AI-чат** — отвечает на вопросы про рекламу, конверсии, бюджеты, CPL, ROMI и смежные темы.
- **Единый интерфейс** — главная с диалогом, блоки каналов (Директ, Метрика, Google Ads и др.), обучение и личный кабинет.
- **Аккаунты пользователей** — регистрация и вход; у каждого своя история чатов.
- **Фокус на маркетинге** — ассистент ограничивается бизнес- и маркетинговыми темами.

Идея: один запрос вместо переключения между рекламными кабинетами и таблицами.

---

## Для кого

- маркетологи и performance-команды  
- агентства и специалисты, которым нужна быстрая сводка по каналам  
- команды, которые хотят AI-помощника именно под маркетинг, а не общий чат

---

## Как это устроено (кратко)

| Часть | Роль |
|--------|------|
| Веб-интерфейс | Экран работы с Kotler |
| Backend API | Авторизация, чаты, сообщения |
| База данных | Пользователи и история диалогов |
| Языковая модель | Генерация ответов ассистента |

Пользователь пишет вопрос → система сохраняет диалог → модель формирует ответ → ответ показывается в чате.
